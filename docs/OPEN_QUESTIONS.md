# 需要确认的问题（开发时采用的默认）

实现 MVP 时按下列默认继续推进。若你希望改成备选项，告诉即可。

## 1. 刮削是否允许自动写入（最重要）

- **默认**：一律人工确认后再写入，即使 ISBN 精确匹配、打分 ≥ 90 也不自动覆盖。
- **备选**：达到阈值（例如 ≥ 90）时自动写入未锁定字段，其余进入待确认队列。

## 2. 是否允许服务整理、重命名书库文件

- **默认**：书库目录只读，不移动、不改名、不把元数据写回原文件。
- **备选**：按 `{author}/{series}/{title}.{ext}` 等模板整理；写回 EPUB/OPF 作为单独开关。

## 3. Google Books API Key

- **默认**：无 Key 也可尝试公开查询；失败（如 429）时仅使用 Open Library 等其他源。
- **备选**：配置 `GOOGLE_BOOKS_API_KEY` 以提高稳定性与配额。官方文档要求公开查询携带 Key。

## 4. 中文刮削源

- **默认**：本阶段只留插件接口，不实现豆瓣等中文源（官方 API 已不可用，非官方途径不稳定且可能违反条款）。
- **备选**：后续以独立插件评估国家图书馆 / 其他合规数据源。

## 5. 家庭多账号与阅读进度

- **默认**：Web 与 OPDS 共用一个 HTTP Basic 账号；本期不做多用户和阅读器进度同步。
- **备选**：家庭多个独立账号，或接入 KOReader kosync / OPDS 2.0 进度。
