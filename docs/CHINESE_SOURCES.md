# 中文书元数据来源调研（2026-11-10）

本轮目标：找出相对合规、稳定、**无需破解、无需绕过反爬** 的中文书元数据源。若有可直接落地的，实现插件并实测；否则只做选项对比，交由你选择后再接入。

## 结论（先看这里）

**本轮不实现新的中文刮削插件。**

原因：目前没有「免 Key、官方授权、可稳定实测」的中文专用接口。Open Library 作为已内置的合规源，已经能命中部分知名中文 ISBN，可继续使用。最接近「合规官方 API」的是上海图书馆开放数据，但必须由使用者自行注册 API Key，本环境没有 Key，不能把未实测的插件当作可用功能上线。

## 来源对比

| 来源 | 类型 | 是否需 Key | 合规性 / 风险 | 覆盖与质量 | 本轮处理 |
| --- | --- | --- | --- | --- | --- |
| Open Library | 公开 API | 否（需合理 User-Agent） | 条款允许非商业查询 | 以英文为主，部分中文 ISBN 有记录（见下方实测） | **已内置**，继续使用 |
| Google Books | 官方 API | 官方要求 Key；无 Key 也可能返回结果 | 官方接口 | 中文覆盖不稳定；无 Key 时易 429 | **已内置**；429 时退避，不阻断其他源 |
| 豆瓣官方 API | 曾有开放平台 | 已无法申请 | 开放平台下线，公开 apikey 会返回错误（如 code 105） | — | **不实现** |
| 豆瓣网页 / Frodo 等非官方接口 | 非官方抓取 | 通常要伪装客户端或处理反爬 | 违反使用条款，有封禁与法律风险 | 中文质量高，但不稳定 | **不实现**（需要绕过反爬） |
| 国家图书馆 OPAC / ISBN 查询页 | 网页检索 | 会话/页面 | 没有面向第三方的稳定公开 API；抓页面属于未授权采集 | 馆藏权威，但结构与风控会变 | **不实现** |
| 上海图书馆开放数据 | 官方 REST API | **是**（注册后邮件下发 API Key） | 官方开放平台，相对合规 | 提供书目列表等接口，可用 `code`（识别码/ISBN）、题名、著者检索；平台亦含数字人文、古籍等数据，现代图书覆盖需用 Key 验证 | **推荐作为下一阶段官方插件**，等你提供 Key 后再实现并实测 |
| 探数 / 易源等商业 ISBN API | 商业 API | 是（付费或注册） | 一般有正式接口文档与授权，需自行看条款与费用 | 宣称中文 ISBN 覆盖较好 | **备选**，需你选择并自行申请 |
| isbn.work 一类非正式 ISBN 接口 | 个人/小站 API | 常见为微信等方式获取 Key | 非正式、可持续性与授权不清晰 | 使用方便但风险高于官方源 | **不建议作为默认源** |

上海图书馆开发者入口与文档（调研时仍可访问）：

- 开放数据平台：https://data.library.sh.cn/index
- 开发指南 / 注册 API Key：https://data1.library.sh.cn/developguide
- 近年接口说明（竞赛文档，含书目列表）：https://data1.library.sh.cn/res/doc/api_2026.pdf
- 书目列表示例路径：`https://data1.library.sh.cn/bib/webapi/instance/list`（参数含 `freetext` / `title` / `person` / `code` / `key`）

无 Key 时上述接口会返回 Key 错误或空，故本轮无法做完整实测。

## Open Library 中文 ISBN 抽查（本轮环境）

在不绕过任何限制的情况下，用公开 API 查询：

- `9787536692930`（《三体》）有命中
- `9787506365437`（《活着》）有命中
- `9787020002207`（《红楼梦》）有记录，题名可能是罗马化如 “Hong lou meng”

说明：OL 可以作为补充，不能替代中文出版目录。题名、作者简介、丛书信息经常不完整或不是简体中文惯用写法，自动写入后仍建议抽查。

## 建议你怎么选（对应开放问题 A）

1. **默认建议**：暂不接新插件，继续用 Open Library +（可选）Google Books；手改并锁定中文题名/作者。
2. **若要官方中文源**：你在上图开放数据平台注册 API Key 后，再做一个 `shanghai_library` 刮削插件（只用官方 HTTP API，不抓网页）。
3. **若接受商业源**：选定探数或易源之一，配置其 Key 后实现插件。

不会默认实现豆瓣或国图页面抓取。
