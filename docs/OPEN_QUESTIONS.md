# 已确认的决定与新的待确认问题

## 已确认（2026-11-10）

### 1. 刮削是否允许自动写入

**已决定**：分数达到可配置阈值（默认 90），或 ISBN 精确命中时，自动写入未锁定字段；低于阈值仍进入 `needs_review`。自动写入记录字段级来源和旧值，可在 Web 上撤销一次。支持对未刮削（`pending`）书目批量自动刮削。

原先默认（一律人工确认）已废弃。

### 2. 是否允许服务整理、重命名书库文件

**已决定**：允许按可配置模板整理改名（例如 `{author}/{series}/{title}.{ext}`），处理非法字符、中文与重名冲突。必须先生成 dry-run 预览，在 Web 上确认后才执行；记录移动日志并支持回滚。只移动/改名，不修改文件内容，不写回 OPF。功能默认关闭（`ORGANIZE_ENABLED`）。`docker-compose` 中书库挂载默认仍只读，启用整理时需改为可写（说明见 README）。移动后同步更新数据库路径。

### 3. Google Books API Key

**已决定**：不强制配置 Key，保持无 Key 尝试；遇到 429 时优雅降级并短时间退避，不影响其他刮削源。仍可选配 `GOOGLE_BOOKS_API_KEY` 以提高配额稳定性。

### 4. 中文刮削源

**已决定**：本轮先调研相对合规、稳定的来源。若有无需破解、无需绕过反爬的可用源则实现插件并实测；否则给出选项对比供选择。

**本轮结论**：未实现新的中文插件。豆瓣官方 API 已不可用，网页/非官方接口有反爬与条款风险，不做抓取。国家图书馆 OPAC 主要为网页查询，没有可直接使用的公开官方 API，不抓页面。Open Library 无需 Key，已实测能命中部分中文 ISBN（如《三体》《活着》）。官方合规且较稳定的选项是「上海图书馆开放数据」（需用户自行注册 API Key），本轮因无 Key 无法完整实测，故未上线插件。对比与建议见 `docs/CHINESE_SOURCES.md`。

### 5. 家庭多账号与阅读进度

**已决定**：维持现状。Web 与 OPDS 共用一个 HTTP Basic 账号，不同步阅读进度。

## 新的待确认问题

### A. 下一步中文元数据源

- **默认（建议）**：先不接入新插件，继续用 Open Library；若要覆盖更多中文馆藏，由你注册「上海图书馆开放数据」API Key 后再加官方插件。
- **备选**：接入需自行申请 Key 的商业 ISBN 接口（探数 / 易源等，需评估费用与条款）；或继续只用 Open Library。不建议做豆瓣网页抓取或国图 OPAC 页面抓取。

### B. 整理执行范围

- **默认**：预览并确认后，按模板处理书库中全部未缺失文件。
- **备选**：仅整理勾选的书或当前筛选结果。

### C. 文件监听轮询间隔

- **默认**：`WATCH_POLL_SECONDS=300`（5 分钟）作为 inotify 的兜底。
- **备选**：缩短到 60 秒（更及时，扫描更频繁）；或在确认 inotify 可靠的本地磁盘上加大间隔 / 关闭轮询。
