# 已确认的决定与新的待确认问题

## 已确认（2026-11-10）

### 1. 刮削是否允许自动写入

**已决定**：分数达到可配置阈值（默认 90），或 ISBN 精确命中时，自动写入未锁定字段；低于阈值仍进入 `needs_review`。自动写入记录字段级来源和旧值，可在 Web 上撤销一次。支持对未刮削（`pending`）书目批量自动刮削。

原先默认（一律人工确认）已废弃。

### 2. 是否允许服务整理、重命名书库文件

**已决定**：允许按可配置模板整理改名（例如 `{author}/{series}/{title}.{ext}`），处理非法字符、中文与重名冲突。必须先生成 dry-run 预览，在 Web 上确认后才执行；记录移动日志并支持回滚。只移动/改名，不修改文件内容，不写回 OPF。功能默认关闭（`ORGANIZE_ENABLED`）。`docker-compose` 中书库挂载默认仍只读，启用整理时需改为可写（说明见 README）。移动后同步更新数据库路径。

### 3. Google Books API Key

**已决定**：不强制配置 Key，保持无 Key 尝试；遇到 429 时优雅降级并短时间退避，不影响其他刮削源。仍可选配 `GOOGLE_BOOKS_API_KEY` 以提高配额稳定性。

### 4. 中文刮削源

**已决定**：本轮先调研相对合规、稳定的来源。若有无需破解、无需绕过反爬的可用源则实现插件并实测；否则给出选项对比供选择。

**后续决定（2026-11-11）**：采用修复版 douban-book-api（https://github.com/zzwen6/douban-book-api，`5996fda`）作为中文刮削源。opds-library 只通过 HTTP 调用该独立服务（开发默认 `http://127.0.0.1:3000`），不在主项目中抓网页。中文书优先豆瓣，其他优先 Open Library。服务可关闭；不可达时不影响其他源。风险与对照见 `docs/CHINESE_SOURCES.md`。

**后续决定（2026-11-11）**：

- 整理范围：预览确认后处理整个书库中全部未缺失文件（不按勾选/筛选）。
- 文件监听轮询兜底：`WATCH_POLL_SECONDS=300`（5 分钟）。
- 中文源采用豆瓣侧车服务；上海图书馆开放数据暂不接入。
- 下载豆瓣封面（仅 `*.doubanio.com`）时使用常见桌面浏览器请求头（User-Agent、`Accept: image/*`、`Referer: https://book.douban.com/`），配置项 `DOUBAN_COVER_BROWSER_HEADERS` 默认 `true`。不使用代理、cookie 或登录。失败（418/403/超时）时保留现有封面、记录原因、不重试。封面字段仍尊重锁定与撤销。

### 5. 家庭多账号与阅读进度

**已决定**：维持现状。Web 与 OPDS 共用一个 HTTP Basic 账号，不同步阅读进度。

## 新的待确认问题

以上 A/B/C 均已决定，见本节「后续决定」。暂无新的待确认问题。
